# Placement Twin Platform

The full application source code is located in the `placement-twin/` directory:

```
placement-twin/
├── frontend/          # React + Vite + Tailwind CSS (Port 5173)
├── backend/           # Node.js + Express (Port 5000)
├── ai-service/        # Python + FastAPI + Qwen2.5-1.5B-Instruct (Port 8000)
└── README.md          # Complete documentation and architecture guide
```

To get started quickly, please refer to [`placement-twin/README.md`](./placement-twin/README.md) or run:

```bash
cd placement-twin
start-all.bat
```
